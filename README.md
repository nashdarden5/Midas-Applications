### Installing BlakeyPoo on an iPhone using Windows
After a successful GitHub Actions build, download the **BlakeyPoo-unsigned-iPhone-IPA** artifact, extract its ZIP, and sign/install the IPA locally with a free Apple ID using [Sideloadly](https://sideloadly.io/). See [BlakeyPoo instructions](apps/BlakeyPoo/README.md).

An unsigned IPA is **not** directly installable. Simulator builds are not iPhone installers.

### Publishing policy
Only app source, app tests, and public build workflows belong here. Private Midas infrastructure, credentials, internal endpoints, logs, handoff, and development history stay in the private Midas repository. New shareable apps get their own `apps/<AppName>/` directory.

## BlakeyPoo web app (recommended for friends)

The no-signing, installable web companion lives in [`docs/`](docs/) and is deployed via [GitHub Pages](.github/workflows/blakeypoo-pages.yml) at **https://nashdarden5.github.io/Midas-Applications/** once GitHub Pages is enabled in repository Settings → Pages → Build and deployment → GitHub Actions. Open the URL in Safari and choose Share → Add to Home Screen. This avoids Sideloadly and developer provisioning. The web app now uses the agreed 1024×1024 BlakeyPoo icon from the private iOS app assets, resized for PWA use. GovDeals opens directly in a browser tab because third-party embedding is unreliable; no automated bidding or account access is provided. Saved auction shortcuts are stored locally on the device.

## BlakeyPoo 2.0 dashboard
The public PWA now includes Discover (opens official GovDeals for real inventory), a local saved-listings dashboard with title/notes search, category and status filters, sorting, a form to save GovDeals URLs with user-entered estimated purchase/fees/resale, and estimated upside totals. Old URL shortcuts are migrated automatically on the same browser. All data is local to each browser; it is **not** a real-time GovDeals feed, cross-device sync, verified market-price service, or bidding system. Approved BlakeyPoo icon remains fixed in the top-right corner of all in-app sections. External GovDeals pages cannot display our icon. `node tests-blakeypoo.cjs` runs security, estimate and migration checks.

### Nearby passenger-vehicle swipe carousel
The Explore page now shows real active **GSA Auctions** vehicle candidates via the official federal GSA Auctions API. A GitHub Pages deployment job refreshes a public, read-only `gsa-vehicles.json` snapshot every six hours. Source photos, latest reported high bid, end date and official listing URL are displayed in a swipeable carousel. A visitor can grant browser location permission to filter by **100 miles**, using GeoNames ZIP centroids (approximate, not street-level). Visitor location stays on device; no coordinates are sent to our server. Results may be empty in areas with no matching federal auctions. GSA feed does **not** cover GovDeals or all auctions, and listing status/prices may change between updates. The app keeps the original approved BlakeyPoo icon and URL. For reliable unattended refresh, configure a personal `GSA_API_KEY` repository secret from api.data.gov; until then the workflow uses the official limited `DEMO_KEY`. Do not expose private keys in client-side JavaScript. GeoNames ZIP data: https://download.geonames.org/export/zip/US.zip (CC BY 4.0).

### GovDeals browsing and transitions
The Browse tab attempts to show the official GovDeals site in an iframe and always provides an Open official GovDeals button for Safari. GovDeals may prohibit iframe embedding using CSP/X-Frame-Options or other security restrictions; BlakeyPoo does not bypass those restrictions, proxy credentials, or impersonate GovDeals. The approved original portrait/gear icon is enlarged to 118px (96px on narrow iPhones), fixed top-left. Navigation uses a brief icon-centered loading overlay that dismisses on the next rendered frame, not an artificial wait. The embedded GovDeals view is not guaranteed to function and must be tested on iPhone.

### Ending-soon and location filters (v10)
The home carousel defaults to **all nationwide active GSA passenger-vehicle candidates, ending soon first** (ascending closing date), without requiring location permission. Optional **Location within** selector: Anywhere, 25, 50, 100, 250 or 500 miles, using ZIP-centroid approximate distances and browser geolocation only when a radius is selected. The GovDeals search button opens the real GovDeals website where its own native location filters can be used; no unverified GovDeals preset URLs or undocumented GovDeals APIs are used. BlakeyPoo does not currently index all GovDeals passenger vehicles. GSA closing timestamps in the current public feed contain dates only, so same-day ordering cannot be guaranteed.

### Real listing photographs and bid cards (v11)
The nationwide ending-soon carousel uses actual current GSA Auctions API records and now snapshots their official public listing photographs as optimized local JPEGs during each six-hour data refresh. Each swipe card prominently displays the auction photograph, item title, **reported current high bid** (not a final sale price), city/state, auction end date, and a link directly to the specific official auction. The photo snapshot is necessary because the GSA image endpoint responds as `application/octet-stream`, which can be unreliable in some mobile browsers. No fictitious photos, listings or prices are generated. This is still a GSA-only feed, not GovDeals inventory; the GovDeals Browse tab links to its official site.

### Independent BlakeyPoo project (v12)
BlakeyPoo is a **separate application**, not part of the Project Midas agent, its automation, or its shared handoff/changelog. Changes here are recorded in this app's own Git history and `BLAKEYPOO_CHANGELOG.md`. The existing GitHub Pages hosting URL remains unchanged for installed users.

The approved BlakeyPoo portrait/gear icon stays large and fixed in the upper-left corner while the page scrolls. Every fresh page load or installed-PWA launch shows a full-screen 2-second startup splash, with the approved icon completing one 360-degree rotation. A restored browser back/forward-cache page also replays the splash, as does returning to an app tab after more than 3 seconds in the background. Reduced-motion preference disables rotation while keeping the 2-second splash. Other tab transitions keep the brief loading overlay. Actual current GSA vehicle listing photos are optimized and linked to specific official GSA auction URLs with reported current bids. This is not a GovDeals inventory feed.

**Photo availability:** GitHub Actions may be blocked by the GSA image CDN (HTTP 403). The feed generator now preserves verified locally cached official images and reuses them on subsequent refreshes. Newly added listings may lack photos if GSA blocks fetching; never invent photos.

### Resale Analysis (v13)
Every real GSA vehicle card now has a green star at the bottom-right. Tap it to enter an estimated purchase cost (pre-filled with current reported bid), shipping/transport, buyer premium percentage, other costs (tax, repairs, fees), and comparable-market resale value. Potential profit = resale value − (purchase cost + purchase cost × buyer premium% + shipping + other costs). The breakdown is shown immediately and can be saved for that specific auction; the star then shows the estimated dollar profit. If inputs are missing, the star says **Analyze** rather than fabricating a profit estimate. All estimates stay in the browser's localStorage; clearing browser storage removes them. A 0% premium is a user-entered assumption, not a statement of GSA auction terms. The app does not currently estimate market resale values or shipping automatically.

### Assisted automatic resale analysis (v14)
The app now generates an approximate transport-cost estimate when the visitor enters a destination US ZIP, using GSA auction ZIP centroids and GeoNames destination ZIP centroids. This is an **illustrative assumption**, not a carrier quote: road miles = 1.25× great-circle distance, transport = $300 + $1.50 per estimated road mile, rounded to the nearest $25. Do not treat it as a verified freight rate. The GSA public auction feed does not provide lot-specific buyer premiums; no premium is invented or automatically set. The app supports linking actual sold comps from `docs/verified-sold-comps.json` with title, USD price, sale date, URL, and verified flag, matched by exact year/make/model. This file intentionally starts empty because no authorized verified-sold feed is connected. eBay's official Marketplace Insights sold-history API is restricted to approved partners. Until a verified sold comparable and buyer premium are available, profit is NOT automatically calculated; the green star remains Analyze unless the user supplies and saves the missing inputs. The resale modal explains unavailable data, links any verifiable comps, and discloses all assumptions.

### Automatic comp-based profit estimates (v15)
A starter set of **five individually checked public sold auction records for 2016 Chevrolet Tahoe** is included, each with a direct sold-listing URL and condition note, sourced from GovAuctions.app's public pages. Matching is strict by year/make/model. For matching lots, the green star now immediately displays a rough profit estimate using current GSA high bid, 0% standard GSA Auctions buyer premium (verify lot terms), estimated transport from destination ZIP or an illustrative $675 for a 250-mile shipment, and the median of available sold comps. No comparable = **No comp**, not an invented price. Repairs, taxes, fees, title issues, mileage/condition differences and future bid increases are **not accounted for** in the automatic figure. A government auction sold price is **not necessarily a retail resale price**. This is a proof-of-function starter dataset, not a comprehensive automatically refreshed sold-price provider. All figures must be reviewed before bidding.

### One-tap GSA vehicle saving and static header icon (v16)
The GSA vehicle carousel includes a **Save to BlakeyPoo** button for each auction. One tap creates a saved Vehicles record with the official GSA link, current reported high bid, auction end date, location and Watching status. Existing saved listings are detected by exact URL to avoid duplicates. The Saved tab opens both GovDeals and GSA links. GovDeals browsing still requires manually saving the URL because its external website does not expose its listings to the carousel. The original large BlakeyPoo icon remains at the top-left of the page but now scrolls away naturally instead of covering the viewport. The 2-second rotating full-screen startup splash is unchanged.

### Vehicle watchlist (v17)
The Saved tab now renders saved GSA vehicle cards with official photos from the latest GSA feed, reported current bids, ending dates, city/state, a green star opening the same resale-analysis dialog, direct auction link, and removal button. Live fields refresh when the public GSA feed refreshes; the stored bid snapshot remains fallback metadata. If a saved auction no longer appears in the active feed, no image or current price is invented; the card explains the listing is missing and links to the auction. Manual GovDeals records remain in Saved with their original editable metadata and link. Filters, sorting, duplicate prevention, and local browser persistence remain intact.

### GovDeals-first discovery and watchlist alerts (v18)
The carousel now puts public GovDeals vehicle auctions from the third-party UX Search GovDeals platform page first, followed by the official GSA Auctions feed. Each GovDeals card links to the actual official GovDeals auction and may be saved in one tap. This is **not** an official GovDeals API: public third-party discovery may be incomplete, stale or unavailable. The feed currently discovers a small subset of featured GovDeals vehicle lots, not all GovDeals inventory. Scheduled GitHub Actions refreshes both sources every six hours and retains the prior GovDeals snapshot if upstream fetch fails. Saved listings show bid changes observed between browser visits and warnings when closing is within 72 or 24 hours; there are no push notifications or background browser checks. Resale comps remain limited to the existing verified records; Autotrader asking prices are not misrepresented as completed sales.
